# QLang Documentation

This documentation is organized by language feature area.

## Sections

[**Statements**](statements/README.md): variable declarations, assignment, control flow, loops, transactions.

[**Expressions**](expressions/README.md): literals, operators, closures, calls, conversions, query expressions.

[**Builtins**](builtins/README.md): builtin functions and methods.

[**Queries**](queries/README.md): select/insert/update/delete grammar and semantics.

[**Types**](types/README.md): primitive, collection, struct, and callable types.

[**Miscellaneous**](misc/README.md): program layout, schema declarations, naming, and failable semantics.
